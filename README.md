# Custom ChatGPT

A modern AI-powered chatbot application built with **PHP, MySQL, HTML, CSS, and JavaScript**. This project allows users to upload PDF documents and interact through a clean, responsive chat interface, providing an intuitive document-based conversation experience.

*Live Demo: https://smartdigisolution.com/LeadManager/home.php

* Features
 AI Chat Interface
 PDF Upload Support
 Document-Based Conversations
 Fully Responsive Design
 Secure File Upload & Validation
 Fast & Lightweight PHP Backend
 Clean & Modern User Interface
